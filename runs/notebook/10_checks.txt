3. THE NUMBER 0.1 IN fp32, bf16 AND fp8 E4M3 (Task 6)
==============================================================================
  Step 1. Write 0.1 as (1 + fraction) x 2^power:  0.1 = 1.6 x 2^-4
  Step 2. The fraction 0.6 in binary, by repeated doubling:
            0.6 x 2 = 1.2  -> bit 1
            0.2 x 2 = 0.4  -> bit 0
            0.4 x 2 = 0.8  -> bit 0
            0.8 x 2 = 1.6  -> bit 1
            0.6 x 2 = 1.2  -> bit 1
            0.2 x 2 = 0.4  -> bit 0
            0.4 x 2 = 0.8  -> bit 0
            0.8 x 2 = 1.6  -> bit 1
            0.6 x 2 = 1.2  -> bit 1
            0.2 x 2 = 0.4  -> bit 0
            0.4 x 2 = 0.8  -> bit 0
            0.8 x 2 = 1.6  -> bit 1
          0.6 = 0.100110011001...  (1001 repeats forever, so every format must round)

  Step 3. Exponent field = power + bias; mantissa = first bits of the fraction, rounded:

  format    s  exponent   mantissa                  stored value          rel. error  PyTorch agrees
  fp32      0  01111011   10011001100110011001101   0.100000001490116     1.49e-08    yes
               = 123 - bias 127 = 2^-4;  mantissa 5033165/8388608 -> (1 + 0.6000000238) x 2^-4
  bf16      0  01111011   1001101                   0.10009765625         9.77e-04    yes
               = 123 - bias 127 = 2^-4;  mantissa 77/128 -> (1 + 0.6015625) x 2^-4
  fp8 E4M3  0  0011       101                       0.1015625             1.56e-02    yes
               = 3 - bias 7 = 2^-4;  mantissa 5/8 -> (1 + 0.625) x 2^-4

  What each format can hold (range is set by exponent bits, detail by mantissa bits):
  format     exp  mant  decimal digits     largest  smallest normal  smallest subnormal
  fp32         8    23             7.2     3.4e+38         1.18e-38             1.4e-45
  bf16         8     7             2.4    3.39e+38         1.18e-38            9.18e-41
  fp16         5    10             3.3    6.55e+04          6.1e-05            5.96e-08
  fp8 E4M3     4     3             1.2         448           0.0156             0.00195
  (fp8 E4M3 has no infinity and only 448 as its top: real fp8 training shares a scale
   per block or tensor, exactly the idea in Section 11.)
